cDarzi OS

A modern live desktop with a flat UI, compact app icons, offline help, and practical wired/wireless connection tools.

Connect to Wi-Fi

  1. Click the network icon in the top panel.
  2. Choose your wireless network.
  3. Enter the password and connect.

If Wi-Fi is blocked, run rfkill unblock wifi. For maximum range, use 2.4 GHz or Ethernet/USB tethering.

Offline browsing

This portal is stored locally, so it works with no internet. Save extra HTML/PDF docs into your home folder for offline use.

Apps

Open the top-left menu for files, terminal, browser, office tools, media, disks, printing, screenshots, and settings.

Hardware diagnostics

Useful commands: nmcli device, ip addr, lsusb, lspci, sudo lshw -C network.
